# 📊 Data Analysis Projects

Welcome to my **Data Analysis Projects** repository! This repo is a collection of various data analysis projects I’ve worked on, covering topics such as data cleaning, visualization, exploratory data analysis (EDA), statistical modeling, and basic machine learning. These projects demonstrate the use of tools like Python, Pandas, NumPy, Matplotlib, and Jupyter Notebooks.

## 🔍 Projects Overview

Each folder in this repository represents a different project. Below is a quick summary of what you can find:

### 1. 🏅 Olympic Medals Prediction
- **Description:** Predicts the number of medals countries will win using linear regression.
- **Tools Used:** Python, Pandas, Scikit-learn, Matplotlib
- **Skills Demonstrated:** Data preprocessing, regression modeling, evaluation metrics

### 2. 📉 Sales Data Analysis
- **Description:** Analyzes historical sales data to uncover trends and insights.
- **Tools Used:** Python, Pandas, Matplotlib
- **Skills Demonstrated:** Time series analysis, data visualization, insights generation

### 3. 📕Analyzing best selling amazon books
- **Description:** Analyze the top selling books on amazon from 2009 to 2019.
- **Tools Used:** Python, Pandas
- **Skills Demonstrated:** Analysis, insights
